# Lineage II EpicTales — Pride Style Updater

Update distribution repository for the
Lineage II EpicTales — Pride Style client.

Public patch and client update files are hosted here so the
EpicTales Pride Updater can Full Check, download only missing
or changed files, verify them, and enable PLAY.

This repository is public distribution only. Signing keys,
credentials, tokens, and publishing secrets are never stored here.
